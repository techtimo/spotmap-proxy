Spotmap Proxy

Infrastructure service

Spotmap is a WordPress plugin that displays live GPS tracks on a map — useful for glider pilots, hikers, or anyone using a satellite communicator. It supports three position sources: OGN/FLARM (glider transponders), Zoleo (satellite messaging devices), and AIS (maritime vessel transponders).

Why does this proxy exist?

All these data sources have a constraint WordPress cannot handle directly:

  • Zoleo pushes GPS events to a single developer-registered webhook URL. There is no per-user API — one endpoint must serve every Spotmap installation.
  • OGN/FLARM requires a persistent TCP connection to the APRS network (aprs.glidernet.org:14580). A PHP-based WordPress site cannot hold an open socket across requests.
  • AIS requires a persistent WebSocket connection to a streaming API. Same constraint as OGN — WordPress cannot maintain long-lived connections.

This service solves these problems. It receives Zoleo webhook pushes, OGN position packets, and AIS vessel positions, looks up which WordPress site each device belongs to, and forwards the data immediately. Routing tables are stored in SQLite; GPS points are never persisted here — they are forwarded and dropped.

Endpoints

Public

  • GET /health — Health check, returns {"ok":true}
  • POST /zoleo — Zoleo webhook receiver

Provision — Authorization: Bearer <PROVISION_KEY>

  • POST /provision/routes/zoleo — Register or update a Zoleo route
  • DELETE /provision/routes/zoleo/:id — Remove own Zoleo route (requires ingest_key in body)
  • POST /provision/routes/ogn — Register or update an OGN/FLARM route
  • DELETE /provision/routes/ogn/:address_type/:device_id — Remove own OGN route (requires ingest_key in body)
  • POST /provision/routes/ais — Register or update an AIS/MMSI route
  • DELETE /provision/routes/ais/:mmsi — Remove own AIS route (requires ingest_key in body)

Admin — Authorization: Bearer <ADMIN_KEY>

  • GET /admin/routes — List all routes (ingest keys redacted)
  • DELETE /admin/routes/zoleo/:id — Force-remove any Zoleo route
  • DELETE /admin/routes/ogn/:address_type/:device_id — Force-remove any OGN route
  • DELETE /admin/routes/ais/:mmsi — Force-remove any AIS route
